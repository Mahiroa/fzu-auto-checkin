配置生成器

填完 1~3 步，页面生成一段 YAML。部署那一步直接打 GitHub 接口，不经过别的服务器。

1登录账号

只用来拼配置，本页不保存

智汇福大 App 登录页填的那个学号。

本页不联网，密码只在这台设备的浏览器里待着，不会上传。

token 会过期，过期要重新抓。没有这个顾虑就用学号密码，能自动续。

2签到位置

高德坐标，学校判定用同一套

定位成功会自动填进上面两格。想核对：在高德坐标拾取器里搜宿舍楼，数字应该对得上。

每次打卡在这个点周围随机取一点，看起来像人在附近走动。填 0 就每次报同一个点。

定位没成功？手动填坐标，格式 119.xxxxx / 26.xxxxx。

浏览器定位要授权，而且只在 HTTPS 下能用。微信里打不开就换 Safari 或 Chrome。这一项不会伪造定位。

3消息提醒

不选就完全静默

已经发出。10 秒内手机没收到，多半是 key 粘错了，回去对一遍。

先选一条路

签到跑在 GitHub 服务器上，所以得有个账号

没有账号走第 4 步，有账号走第 5 步。两条路配出来的东西一样。

没有 GitHub 账号走第 4 步：先注册，再照 1~4 条手动粘配置 已有 GitHub 账号走第 5 步：贴一个 token，页面替你建私有仓库、写配置

4手动配置

没有 GitHub 账号

生成配置后，下面有一步一步的引导，照着做。

GitHub 国内直连时好时坏，只有注册和配置那几分钟可能打不开：换个时间、用校园网或手机热点，有梯子就开着。配好之后就不用了，签到跑在 GitHub 服务器上，日常零操作。

这段贴进你自己的私有仓库就行。

  1. 没有账号先注册：点这里免费注册，一分钟，要邮箱。
  2. 把项目导入你自己的私有仓库：clone URL 填 https://github.com/Mahiroa/fzu-auto-checkin，仓库名随意，可见性选 Private，点 Begin import。
  3. 导入完进仓库的 Settings → Secrets and variables → Actions → New repository secret，Name 填 CONFIG_YAML，Secret 粘上面复制的那段，点 Add secret。
  4. 到此为止。之后每晚 21:35 和 21:50 自动签到，记录在仓库的 Actions 页。想收微信通知回第 3 步开推送。

存成仓库根目录的 config.yaml，需要一台常开的电脑。

细节见仓库 README。

5一键部署

已有 GitHub 账号

没有账号回上面走第 4 步。

贴一个 token：页面替你建私有仓库、写入全部代码和你的配置，之后每晚 21:35 和 21:50 自动签到。凭据只存在你自己的私有仓库里。

没有？点这里创建，直达创建表单，repo 和 workflow 两项已经勾好。三件事：Expiration 选 No expiration，默认 30 天到期后写入会静默失败；拉到页面底部点 Generate token；复制出现的 ghp_ 那串，只显示这一次。部署完建议把 token 删掉。
