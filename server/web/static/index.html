    时间调度

    北京时间。开始时间和结束时间当天都算在窗口内；结束时间写成 23:59 时会自动算到 23:59:59。窗口不能跨过半夜，结束时间必须晚于开始时间。

    签到时刻 （可以加多个，精确到分钟就行）

    加了浮动以后，算出来的时刻要是跑出窗口，会重新抽（最多 8 次）；还是出界就贴到窗口边上，并在真正打卡前再核对一次 —— 浮动再多也不会在窗口外打卡。早到最多等多久：比目标时刻早到时最多等这么多分钟，等不到就不打这一档。晚多少分钟还算准点：比目标时刻晚不超过这个分钟数仍算准点，超过就算迟到，但照样会签。
